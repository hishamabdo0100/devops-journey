## 🧪 Practical Labs

### Git & GitHub

Practiced repository management, staging, commits, pushing changes, and branching.

**Commands practiced:**

* `git status`
* `git add`
* `git commit`
* `git push`
* Branch creation and merging

### Linux

Hands-on practice in Ubuntu Server running in VirtualBox, accessed through SSH from Windows.

**Topics covered:**

* Directory navigation and file operations
* Reading files and inspecting logs
* Searching logs with `grep`
* File permissions with `chmod`
* Ownership with `chown`
* Administrative commands with `sudo`
* User and group management
* Inspecting user and group records with `id` and `getent`

**Lab documentation:** [Linux Labs](linux-lab/README.md)
